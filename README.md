## 📌 Executive Summary
This repository contains a comprehensive, end-to-end project portfolio demonstrating the digitalization of a manual grant application process for a NGO. 


## ⚙️ How to Navigate
1. Technical diagram source files are located in the `/bpmn` and `/adr` directories.
2. Formatted Markdown documentation is organized by sprint in the `/docs` directory.
3. This repository serves as the practical foundation for my application for a **verkürzte Ausbildung / betriebliche Umschulung zum Kaufmann für Digitalisierungsmanagement**.
